# Автоматизированный пайплайн обработки данных с Gemini API

Данный проект представляет собой пайплайн на Python в виде Jupyter Notebook для автоматического составления краткого содержания новостей с использованием бесплатной модели Gemini 2.5 Flash.

## 📌 Задачи пайплайна
1. В `pipeline.ipynb` у вас запрашивается ссылка на новость.
2. Скрипт скачивает содержимое статьи по ссылке с помощью `requests` и `BeautifulSoup`.
3. На основе спарсенных данных создается файл `input.csv`: в нем сохраняются URL, заголовок и извлеченный текст.
4. Текст новости отправляется в Google Gemini API , которая генерирует краткое содержание.
5. Полный JSON-ответ модели выводится на экран прямо в ноутбуке и дополнительно сохраняется в файл `output_results.json`.

## 🛠 Установка и запуск

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.9 или выше.
Установите необходимые зависимости из файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 2. Получение и настройка API-ключа
Ваш ключ доступа сохраняем в `.env` в корневой директории проекта.

В файле `.env` указано:
```env
GEMINI_API_KEY=ваш_ключ
```

### 3. Запуск пайплайна
Пайплайн настроен для работы в Jupyter Notebook:
1. Откройте файл `pipeline.ipynb`.
2. Запускайте ячейки сверху вниз.
3. Во время выполнения второй ячейки скрипт попросит вас ввести URL-адрес новости. Вставьте ссылку и нажмите Enter.
4. Дождитесь завершения генерации. Полный JSON-ответ модели появится прямо под ячейкой, а также сохранится в `output_results.json`, а исходные данные — в `input.csv`.

## 📁 Файлы проекта
* `pipeline.ipynb` — основной Jupyter Notebook с логикой пайплайна.
* `requirements.txt` — список пакетов Python.
* `.env` — файл конфигурации с API-ключом, не передается через git.
* `input.csv` — файл, создаваемый скриптом для сохранения исходного текста и заголовка новости.
* `output_results.json` — файл, в который скрипт сохраняет полный JSON-ответ модели.
